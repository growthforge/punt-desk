# Punt · Value Desk

Static PWA: daily value plan + practice (paper) wallet. Data in `data/*.json`, updated by committing JSON.
Model estimates, not guarantees. National Gambling Helpline 0808 8020 133 · GAMSTOP.

- `data/index.json` — list of days (`latest` = day shown on Today)
- `data/plan-YYYY-MM-DD.json` — plan for a day
- `data/wallet.json` — paper wallet (£100 start, practice money only)
